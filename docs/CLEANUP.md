# Cleanup — provably unreferenced files, 2026-11-13

Run during the `build/ios16-root.img` population (loop mount in `/var/tmp/populate-root.N32cV0`,
`tooling/33-populate-root.sh` running). Nothing below is on the populate path; `build/ios16-root.img`,
`build/rd-root.stage`, `build/ipsw-x/*.dmg` (the mounted ones) and `tooling/` are untouched.

## Method

Per candidate, in this order:

1. `git ls-files --error-unmatch PATH` — tracked or not.
2. repo-wide grep for the **basename and the path**: `rg -n -w -F NAME docs/ tooling/ avicii/
   xnu-avicii/ .github/ *.md`, excluding `refs/`, `logs/`, `build/ipsw-x/` and the artifact dirs
   themselves. Every hit inspected: a prose mention is not a reference, a script that reads the
   file is; a hit on a *different* project's identically named file (`anonbeat1-NOTES.md` describes
   spacewar's `t4`/`t5`/`t6`) is not a reference either.
3. A dir listed in a `SHA256SUMS` that a documented `sha256sum -c` command consumes counts as
   referenced (`docs/DIAG.md:90`); a dir only named in prose does not.
4. `du -s --block-size=1` for what the delete actually reclaims (several images are sparse:
   `build/fake-ipsw` is 7.0 G apparent and **0 bytes** on disk).

Also checked: nothing in the delete set is inside a `mount` (only `build/ios16-root.img` and the
three `build/ipsw-x` DMGs are mounted), and `logs/qemu/` had no directory newer than 19:00 while
this ran at ~19:40, so no QEMU run was writing into the set.
