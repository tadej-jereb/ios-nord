## Undo, at any point

- **Back to LineageOS:** `fastboot --set-active=b`.
- **Stock `boot_a`:** `fastboot flash boot_a backup/64f70df8/boot_a.img` (md5 `e7be3c92…20b0`).
- **CPU rendering without a reflash:** boot without `sweetgles=1`, or over SSH:

  ```
  mv /System/Library/Extensions/SweetGLES.bundle /var/root/gpu/SweetGLES.bundle.off
  kill <backboardd pid>
  ```

- **Undo the 10-bit framebuffer switch:** restore `logs/phone/prefs/com.apple.backboardd.orig.plist` to
  `/var/mobile/Library/Preferences/com.apple.backboardd.plist` (owner mobile, 0600).

Hard-won facts:
- QuartzCore ends each frame with `glFlush` only, so the shim must wait for the GPU there.
- IOSurface seeds never change on CPU writes, so every format is imported zero-copy.
- `CAEnableDeepFramebuffer=false` avoids the `'b3a8'` framebuffer.
